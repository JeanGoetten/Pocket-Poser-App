Pocket Poser

Import or record a single-person video, review the selection, and send it to NVIDIA Body Pose (Nova-77) for 3D skeletal estimation after explicit consent. Google ML Kit is used locally only to help locate the subject before upload. Preview and export pose data.

Processing sequence

01

Attach or record

Select a local video or record through the Android camera application.

02

Review and prepare

Choose a time range, optionally set a focus window, and press Next to start preparation.

03

Preview

Inspect the NVIDIA Nova-77 skeleton in 3D. Tracking and estimated poses may be inaccurate when parts of the body are obscured.

04

Export

Save a project or share JSONL pose data, applying selected frame filters.

Install and build

Install on Android

  1. Download the 0.8.0 APK using the link above.
  2. Open the APK on an Android 8.0+ device with a compatible ARM processor.
  3. Allow installation from that source when prompted by Android.
  4. Read the privacy notice. Remote inference requires your own NVIDIA API key and applicable service permissions.

An offline synthetic preview is available for testing the interface.

Build from source

Requires JDK 17, Android SDK Platform 35 and Build Tools 35.0.0. Set ANDROID_HOME to the SDK directory. No separate offline pose-model download is needed.

Windows / PowerShell

git clone https://github.com/JeanGoetten/Pocket-Poser-App.git
cd Pocket-Poser-App
.\gradlew.bat :app:assembleDebug

Linux / macOS

git clone https://github.com/JeanGoetten/Pocket-Poser-App.git
cd Pocket-Poser-App
./gradlew :app:assembleDebug

Output: app/build/outputs/apk/debug/app-debug.apk. Debug builds are for testing only, not production use.

Current limitations

NVIDIA Nova-77 is the only engine that generates 3D poses. It requires a personal NVIDIA API key, applicable account permissions and separate consent to send an audio-free video and technical tracking data to the NVIDIA service. NVIDIA may impose usage limits or fees. Google ML Kit is an auxiliary on-device person-box detector; it does not generate 3D poses. The SDK may independently communicate technical diagnostics or settings.

Single-person detection is experimental. A high tracking-coverage percentage does not guarantee correct skeletal geometry; occluded limbs may be estimated incorrectly. No automatic Unity retargeting or full animated avatar export is provided. This is an early-access application for evaluation, not a guarantee of production readiness. See privacy details and release notes.
