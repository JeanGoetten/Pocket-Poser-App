# Pocket Poser 0.7.0-beta.1 — source-only preview

Public source refresh: 20 October 2026. **No APK of this version is offered publicly.** The current public APK remains v0.6.0-beta.1.

## Changes

- Select NVIDIA Nova-77 (remote), ML Kit 33-landmark inference (offline), or MediaPipe Lite 33-landmark inference (offline).
- Native topology and missing-point handling for each model; low-visibility predicted points can be displayed with dashed edges rather than removed from the preview.
- User permission for NVIDIA remote transfer is separate and optional; offline inference requires no NVIDIA API key.
- Updated video trim behavior and local tracking performance improvements.
- Quality is experimental; 3D retargeting to humanoid Unity meshes is not implemented.

## Verifications and distribution

The private development variant passed 171 JVM tests and an Android two-engine QA run on a short sample. The difficult real-world beach-running clip was not verified in that automated run. These results are not evidence of production readiness.

The public source intentionally excludes the MediaPipe Lite pretrained model binary and all private Git history. Obtain the exact model independently and verify its hash according to [MODEL setup](../MODELS.md). Confirm redistribution terms, upstream SDK diagnostic disclosures, privacy obligations, and production signing before producing a new downloadable APK. The prior public prerelease remains a separate tested binary.
