# Pocket Poser 0.8.0

**Public Android early-access release — 23 October 2026.**

- Single inference engine: NVIDIA Body Pose (Nova-77) over direct TLS connection.
- Removed local ML Kit pose inference, MediaPipe mode, embedded MediaPipe model and engine selection UI.
- Retained Google ML Kit **only for local person bounding boxes** before NVIDIA processing.
- Simplified the 3D viewer and parser to support native Nova-77 poses; no support for legacy local Pose33 projects.
- Updated remote processing and consent disclosures in English and Portuguese.
- Input video selection, review, preparation, recovery, 3D preview, JSONL export and synthetic demo remain.

**Restrictions:** users need their own NVIDIA API key and service allowance. One person per video, approximate motion quality and tracking coverage, no Unity-ready rig. No Play Store distribution. Installation uses an APK downloaded directly from GitHub.

This is a normal GitHub Release for discoverability and evaluation, not a claim of production robustness or comprehensive legal/compliance certification. Device-level acceptance of this specific binary and NVIDIA inference with personal footage were not performed by the release automation.
