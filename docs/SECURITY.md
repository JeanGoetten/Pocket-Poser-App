# Security

Report suspected security flaws privately rather than posting credentials, device captures, personal media or exploit details in a public issue. Do not include NVIDIA API keys or other secret material in reports.

This repository contains only an independently generated public commit history. Public builds are distributed only through reviewed GitHub Releases after validation. No developer keys, local SDK paths or signing keystores are included.

For reproducible local tests, use the Gradle Wrapper and configure the Android SDK on your own machine. Never commit `local.properties`, credentials, keystores or personal recordings.
